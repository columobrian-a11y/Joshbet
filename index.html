How this site actually saves your diary

      

        This is a static site — just HTML, CSS and JavaScript, no server or
        database. It's deployed through Netlify from your GitHub repo.
        Your entries live in data.js, and every visitor sees
        whatever is committed to that file, on any device — not just your
        own browser.
      


      
Add a diary entry

      
    
        
  1. Go to the Add entry tab and fill in the form.
    2. 
        
  2. Click Generate code and copy the block it produces.
    3. 
        
  3. On GitHub, open data.js, click the pencil (edit) icon.
    4. 
        
  4. Paste your new entry inside the entries: [ ] list — add a comma after the entry before it.
    5. 
        
  5. Scroll down and click Commit changes.
    6. 
        
  6. Netlify redeploys automatically in ~30 seconds. Refresh the site.
    7. 
      


      
Add a photo

      
    
        
  1. On GitHub, open the photos folder.
    2. 
        
  2. Click Add file → Upload files and upload your image (keep the filename simple, e.g. beach-run.jpg).
    3. 
        
  3. Commit the upload.
    4. 
        
  4. In your entry's photos list in data.js, add the path: "photos/beach-run.jpg"
    5. 
      


      
Add or rename a habit

      

        Edit the HABIT_LIST array at the top of data.js,
        then make sure every entry's habits object uses the same
        names (true/false for each).
      


      

        Every file in this project (index.html, style.css, script.js,
        data.js) has comments explaining what each part does and where to
        make changes — open them in GitHub's editor whenever you want to
        tweak the design or add a feature.
